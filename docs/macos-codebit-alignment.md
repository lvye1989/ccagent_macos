## 启动

本地 Web（构建产物已更新）：

```bash
npm run web
```

CLI 首次使用先登录账户，再按需运行配置向导。历史数据可通过 Web 设置中的“数据导入”迁入当前账户。

自建后台使用 Node.js 24，在 `cloud/` 下按 `.env.example` 配置数据库和认证环境，运行迁移后构建并启动；默认地址为 `http://127.0.0.1:4310`，入口为 `/login`、`/account`、`/admin`。管理员初始化命令仅适用于指定的已验证账户，参见 `cloud/scripts/create-admin.ts`。

当前 `desktop:dist` 构建 Windows x64 安装包。macOS 使用 CLI 或本地 Web。
