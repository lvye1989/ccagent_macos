## 隔离环境与覆盖

云端测试使用临时 PostgreSQL 17.12、独立测试数据库和随机命名的测试 schema。数据库只监听本机回环地址；连接使用临时 CA 签发的证书，继续执行证书信任和主机名校验。业务连接使用受限的 `ccagent_runtime` 角色，迁移连接独立。测试环境未使用线上数据库连接或真实资金。

覆盖真实登录会话、账户桥接、角色权限、密钥管理、管理筛选、配置审计、数据库结构与迁移异常、TLS 拒绝行为、加密服务凭据、SSRF 限制、价格与计费、支付状态机、图像任务、管理连接测试、维护任务、事务回滚、钱包锁和并发授权结算。供应商与支付网络交互使用各测试原有的合成响应。

本轮修正 `cloud/tests/operations-overview.test.ts` 的日期依赖：较早订单原先由当前日期倒推，而共享历史订单使用固定日期。时间推移后，预期的最早五笔订单发生变化。新增订单现以共享历史日期倒推，继续断言真实查询的排序及数量，完整 234 项复测通过。后台排序实现无需修改。

## 外部依赖与未完成验收

本机没有 Vercel Blob 存储凭据，连接器要求重新认证。以下六个测试文件依赖真实私有存储，未计入上述 234 项通过结果：

- `cloud/tests/files.test.ts`
- `cloud/tests/call-identifiers.test.ts`
- `cloud/tests/gateway.test.ts`
- `cloud/tests/gateway-fallback.test.ts`
- `cloud/tests/native-fallback.test.ts`
- `cloud/tests/qwen-pricing-gateway.test.ts`

初次扩展测试在备用服务结果重放处失败：预期 HTTP 200，实际 HTTP 409。诊断确认，无存储凭据时无法保存私有结果，后续重放返回 `RESULT_UNAVAILABLE`；此路径保留原有防重复请求行为。后续依赖子测试等待供应商夹具信号，探测进程已停止。该组仍需配置真实测试存储后完整运行，不能归入通过结果。线上设置页显示存储已配置，仅凭状态标签不能验收上传、读取和清理。

真实商户充值与退款、邮件送达、收费模型调用，以及 Rhino、Photoshop、SketchUp、ComfyUI 等实际软件联调，保留为独立验收项目。当前桌面安装包脚本仍面向 Windows x64；macOS 使用 CLI 或本地 Web。
